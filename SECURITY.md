# Security

The Citizen of Earth project and website runs entirely in your browser and stores nothing on a server,
but if you find a problem, please tell me.

**I Preferred:** use GitHub's private reporting
(Security tab → "Report a vulnerability").

**Alternative ways:** DM me on TikTok, linked from https://noiz.bio/kiwihtml where some more stuff are

Please don't post details publicly until I've had a chance to fix it.
This is a hobby project, so I can't promise a fixed response time,
but I'll do my best to reply quickly.
